# WeMine Test Automation

This directory contains the proposed test automation implementation for the WeMine application.

## Automation Tools

- Appium - Mobile UI automation
- REST Assured - API automation
- Java - Programming language
- JUnit - Test framework

## Automated Flows

The automation implementation focuses on the following critical flows:

1. Sign In
2. Equipment Inspection
3. Safety Hazard Report

## Project Structure

The automation project will contain reusable components for mobile UI testing, API testing, utilities, and automated test scenarios.
